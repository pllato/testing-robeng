Канбан-доска с кастомными этапами под бизнес-процесс компании

Этапы воронки лидов (настраиваемые)

1. Новый лид
Лид только попал в систему (из Tilda, WhatsApp, вручную)
🤖 Автоматически: приветственное сообщение в WhatsApp
2. Квалификация
Первый контакт установлен, интерес подтверждён
3. Консультация
Проведена онлайн- или офлайн-консультация по программе
🤖 Если нет активности 3 дня → задача менеджеру
4. Договор
Клиент готов, формируется договор
5. Обучение
Клиент оплатил, начался процесс подготовки
6. Завершён / Отказ
Клиент завершил обучение или отказался

3
💬 WhatsApp интеграция
Два типа интеграции: серый (GreenAPI) + официальный (WABA)

Тип 1: GreenAPI (основная переписка)

✅Каждый менеджер — свой WhatsApp номер внутри CRM (~8 000 ₸/мес за канал)
✅Входящее сообщение → автоматически создаётся лид в CRM
✅Вся история переписки видна директору и РОПу
✅Отправка текста, файлов, фото, голосовых, видео (лимит сервера)
✅Переписка отображается внутри карточки клиента
✅Массовые рассылки: выбор сегмента → отправка с rate-limiting
🔶Шаблоны быстрых ответов

Тип 2: WhatsApp Business API (официальный)

✅Отправка шаблонных уведомлений: подтверждения записи, напоминания
✅Интеграция с верифицированным номером компании
🔶Стоимость от Meta: 10–15 ₸ за исходящее сообщение (оплата клиентом)

Распределение лидов по WhatsApp

✅Входящий WhatsApp → автоматически назначается ответственный по правилу
✅Правила: по очереди, кто онлайн, по сменам (5/2 с настраиваемым расписанием)
✅Ручное переназначение директором/РОПом

Технические требования
Платформа и инфраструктура
Минимальные требования для корректной работы системы.
✅Браузеры: Chrome 110+, Safari 16+, Firefox 110+, мобильный Chrome/Safari
✅Одновременных пользователей: до 50 без деградации производительности
✅PWA: установка на телефон через браузер, push-уведомления, работа при плохом интернете
✅Хостинг: сервер клиента или бесплатный хостинг Pllato (10 GB включено)
✅Время отклика интерфейса: < 300 мс для стандартных действий
✅Резервное копирование данных: автоматически каждые 24 часа
🔶При росте >50 пользователей: рефакторинг (~10–20 часов, по тарифу 2 000 ₸/час)
